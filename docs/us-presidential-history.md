# U.S. presidential history

The archive includes all 60 completed presidential elections, from 1788–89 through 2024. Records are published through the existing Supabase world election archive and remain editable by moderators. The existing 2020 and 2024 IDs are retained.

National Archives electoral tables supply the actual counted presidential votes and state allocations. UCSB's American Presidency Project supplies historical popular-vote tables; FEC compilations supply the 2016, 2020 and 2024 popular votes. Named candidates in the historical tables are retained, with residual minor-candidate votes grouped explicitly. This is complete election coverage, not a claim that every minor candidate is separately named. A comparable national popular total is unavailable before 1824; those values remain null. The 1824 popular tally also covers only recorded voting states. Source definitions and historical compilations can differ.

The Electoral College's original system gave every elector two undifferentiated votes through 1800. These tables include both votes and explain the doubled totals. Jefferson's 1800 tie and John Quincy Adams's 1824 House election are represented correctly. Rejected, uncast and faithless votes are retained; the map shows actual electoral recipients rather than pledged totals or popular-vote winners. The National Archives 1800 HTML table omits Virginia's 21 Burr votes: the original tally, NAID 2668821, confirms them and is linked on that record. Other grouped recipients are disaggregated from the Archives' table footnotes.

The map uses our existing Census / US Atlas modern outlines as a geographic reference, with an explicit warning that these are not historical boundaries. Areas not participating or without counted votes remain gray. Stripes identify multiple recipients or uncast/rejected votes. A keyboard-accessible selector and state panel expose exact allocations, including Maine, Nebraska and DC. The historical elector counts are used for each year. No new database queries, tables or map services are needed by the map.

Rebuild the public import templates and map data with `python scripts/import-us-presidential.py`. The importer uses a local `.cache/us-presidential` source cache and requires `curl` and Poppler's `pdftotext`. An existing cache can be passed with `--source-directory PATH`. It validates state columns and footnote disaggregations before producing `scripts/us-presidential-election-records.json`, `public/us-presidential-electoral.json` and the source hashes / audit in `scripts/us-presidential-sources.json`. It never writes to the database automatically.

Run `node --test scripts/check-us-presidential.mjs`, `pnpm typecheck`, `pnpm test` and `pnpm build`. Database imports must validate these records, preserve existing IDs, use an atomic transaction and guard existing versions against concurrent edits. Do not reintroduce withdrawn records through a frontend fallback.
