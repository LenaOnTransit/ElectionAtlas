# Confirmed calendar extension through 31 December 2027

Reviewed on 8 October 2026. Adds 25 national/territorial executive and legislative records and confirms the exact date of five existing 2027 elections. Two existing Haitian records have their polling dates marked unannounced pending the CEP revised calendar; its 5 October notice specifically postpones campaigning. Four territory directory entries support labels and country filters. Historical results and edited candidate data are preserved.

Every confirmed executive/legislative election in the IFES upcoming list and full-year 2027 confirmed search was compared with the existing public calendar. Additional official or reported election-authority announcements cover Germany, Finland, Micronesia, Gambia, Kyrgyzstan, El Salvador, Burundi, Kenya, Mexico, Switzerland, Grenada and the conditional Czech Senate runoff. The source for each decision is attached to its record. The patch contains previous payloads for updates so publication can require exact equality and abort on concurrent edits.

“Confirmed” describes an announced date, not a guarantee the election will proceed. Conditional runoffs are labelled explicitly. Swiss Council of States dates vary by canton: the entry is an overview of the main October voting day. Referendums, local elections and year-only expectations are outside this patch. Guatemala's preliminary timetable and constitutional deadlines are not promoted to confirmed dates. See coverage-audit.json.

Rebuild: install beautifulsoup4; save the public IFES upcoming HTML as .cache/calendar/ifes-upcoming.html and https://www.electionguide.org/electionresults/?years%5B%5D=2027&status_ids%5B%5D=1 as ifes2027.html; save the current country directory and upcoming records as inventory.json in the same folder. Run python scripts/import-confirmed-calendar.py, review all changes and run node scripts/check-confirmed-calendar.mjs. Source hashes identify the reviewed snapshots; later snapshots require a new review. The generator never publishes.
