# Iceland national election archive

75 records, 70 result tables and 334 result rows: the 1844 restored Althing election, 46 general elections from 1874–2024, five separate nationwide upper-house ballots (including the October 1926 by-election), 22 presidential selections/returns from 1944–2024, and the annulled 2010 Constitutional Assembly ballot. This is not a claim of complete nineteenth-century coverage.

Statistics Iceland JSON-stat snapshots supply modern parliamentary results (KOS02121), detailed 2024 results (KOS02018), historical general/upper-house turnout (KOS02001/KOS02002), and presidential results and turnout (KOS07112, KOS07110, KOS07100, KOS02004). Their API URLs and source URLs are retained in the generated records. For reproduction, POST a query selecting all category, organization and year values, national constituency and total sex where those dimensions exist, with response format `json-stat2` to the corresponding Statistics Iceland PX API table.

The detailed 2024 table includes 42 Responsible Future votes omitted from the long-run table; its reconciled total is 212,470. The existing 2024 archive ID, government summary and snap-election metadata are preserved. Historical web source snapshots and parsed extracts retain the source tables used for older allocations. The erroneous 11 April 1908 label in the turnout series is overridden with the verified 10 September election date.

Early nonparty tables count elected representatives only, excluding appointees. Bicameral general-election tables can include continuing upper-house members; their notes explain this. Separate upper-house ballots describe the cohort actually contested. Fractional historical allocations are retained exactly in reconciliation notes, with integer-only vote fields left empty rather than rounded. Five elections (1902, 1903, 1908, 1911, 1914) have dates and turnout but no verified national party breakdown. Unopposed presidential returns have no invented popular vote totals or turnout. The 1944 selection records parliamentary electoral votes. The 2010 ballot has no elected/winner flags because its result was annulled.

Regenerate with `python scripts/import-iceland-elections.py` and `python scripts/build-iceland-import-sql.py`. Run `node scripts/check-iceland-elections.mjs`. The SQL is additive, idempotent and guarded against changed baseline content; the baseline backup is included. Country coverage updates last. Existing first-round or unrelated records are untouched.
